## 背景

社团的飞行训练服务器最近有点不对劲。

值夜的同学说，雷达上偶尔会飘过一些"不该存在的目标"——它们以民航机绝无可能的速度掠过，有时候干脆从地底下钻出来。地勤记录里管这叫「幽灵航迹」（Ghost Track）。

老社员们对此讳莫如深，只留下一句话：

> *"模拟器不会撒谎。但撒谎的方式，有很多种。"*

你被授权接入训练服务器。三个任务，三个 flag。

祝好运。

## 〇、环境准备（必读，做不完这一步后面全是零）

### 0.1 硬件与系统要求

| 项目 | 要求 |
|---|---|
| 运行方式 | **物理机**，不得在虚拟机内运行 |
| 虚拟化 | **必须关闭**（见 0.2） |
| 操作系统 | Ubuntu 22.04 LTS（推荐，提供预装镜像）/ Windows 10 1809+ |
| 显卡 | 支持 OpenGL 3.3+，显存 ≥ 2GB |
| 内存 | ≥ 8 GB |
| 磁盘 | ≥ 20 GB 可用空间 |
| 网络 | 需 UDP 出网，可访问训练服务器 |

### 0.2 关闭虚拟化

反作弊会在启动时检测虚拟化环境。**检测到虚拟化将直接拒绝启动**，没有例外。

请**在开赛前**完成以下操作并用自检工具验证：

**Windows**

1. 关闭 Hyper-V（管理员权限，执行后重启）：
   ```
   bcdedit /set hypervisorlaunchtype off
   ```
2. 关闭「核心隔离 / 内存完整性」：Windows 安全中心 → 设备安全性 → 核心隔离 → 内存完整性 → 关
3. 关闭 WSL2（如已安装）：
   ```
   wsl --shutdown
   dism.exe /Online /Disable-Feature:Microsoft-Windows-Subsystem-Linux
   ```
4. 关闭虚拟机平台：`dism.exe /Online /Disable-Feature:VirtualMachinePlatform`
5. BIOS 中关闭 VT-x / SVM（如上述步骤后仍被拦截）

**Linux**

1. 卸载 kvm 模块：`sudo modprobe -r kvm_intel kvm`（或 `kvm_amd`）
2. BIOS 中关闭 VT-x / SVM
3. 如使用 Docker，需停止相关服务

> **注意**：部分杀毒软件与第三方反作弊自带虚拟化层。如遇拦截，请携带自检工具输出联系组委会，我们将人工判定是否放行。

### 0.3 安装与自检

```bash
# 1. 拉取赛事环境（含 FlightGear 与反作弊，已锁定版本）
./install.sh

# 2. 环境自检（检查虚拟化、依赖、版本、文件完整性）
./anticheat-selfcheck

# 3. 看到 [OK] Environment ready 后方可开始
```

自检未通过时，工具会**明确指出是哪一项不合格**并给出修复建议。请勿跳过。

### 0.4 启动

```bash
./launcher.sh --callsign=<你的队伍ID>
```

脚本会自动完成：参数校验 → 文件完整性校验 → 启动反作弊 → 启动 FlightGear → 注册训练服务器。

**反作弊窗口请勿关闭。** 关闭即断开心跳，当前会话全部作废。

看到 FlightGear 主界面与右上角 `CONNECTED` 指示灯后，即可开始。

## 二、任务

### Task 1 · 进近（30 分）

**「先把飞机落下来。」**

从指定起始点起飞，在指定机场的指定跑道完成一次 ILS 进近并安全落地。

**要求**

- 跑道与频率在服务器公告中给出
- 落地需满足基本的进近稳定性与接地品质要求
- **允许全程使用内置 AP**——不会手动飞行不构成障碍

**计分**：分档计分。落地成功 / 进近稳定 / 接地品质，各自独立给分。摔了也能拿一部分，前提是落下来了。

**提交**：落地后自动提交，判定结果在服务器公告中返回。

---

### Task 2 · 幽灵航迹（30 分）

**「雷达上的那些目标，它们要去哪？」**

我们在训练服务器的记录里截获了一段残缺的领航日志。日志指向一个坐标——但给出坐标的那部分已经损坏了，只剩下三条定位读数。

**你拿到的东西**

```
[NAV LOG - PARTIAL RECOVERY]
----------------------------
STATION  A : ident ______  freq ______   DME   ______
STATION  B : ident ______  freq ______   DME   ______
STATION  C : ident ______  freq ______   RADIAL ______
----------------------------
注：读数自目标点观测所得。
```

（`______` 处为服务器按你的 callsign 下发的实际数值）

**你要做的**

1. 从读数还原出目标点坐标
2. 飞过去，在其上方通过

**要求**

- 进入目标点水平半径内，且高度低于指定值，**并持续一段时间**
- 擦边不算，瞬移不算

**提示**：两个距离圈会交于**两个**点。第三条读数是用来做决定的——它只知道方位，不知道距离。

---

### Task 3 · 飞天遁地（40 分）

**「模拟器不会撒谎。但撒谎的方式，有很多种。」**

在**默认飞行模型（JSBSim）**、**反作弊正常运行**的前提下，让模拟器**稳定地**报出超越机体结构极限的飞行状态，并让反作弊为这段飞行签出有效票据。

**三个检查点**

| 代号 | 条件 | 需持续 |
|---|---|---|
| **飞天** | 气压高度 > 100,000 ft | ≥ 10 秒 |
| **遁地** | 离地高度 < −300 ft | ≥ 10 秒 |
| **超速** | 空速 > 3 × VNE | ≥ 15 秒 |

**要求**

- 状态必须**连续、平滑**。瞬移、跳变、单帧尖峰一律不认
- 必须由**正常运行的反作弊**为此段飞行签出有效票据
- 达成任意 2 个检查点给部分分，全达成给满分

**说明**

- 训练服务器会为本题提供**独立频道**，请在独立频道内操作（公共频道内请不要表演）
- 本题**不限制**你如何实现。这是附加题的附加题。

**提交**：达成后服务器自动判定，通过后 flag 在排行榜显示。

## 四、FAQ

**Q：我完全不会开飞机，能做吗？**
A：Task 1 允许全程 AP，跟着教程配置好频率、接通 APP 即可。Task 2 需要你飞到某处，同样可以 AP 完成。Task 3 与飞行技术基本无关。

**Q：为什么非要关虚拟化？我在虚拟机里跑得好好的。**
A：这是附加题的一部分设计。如果你有无法关闭虚拟化的硬性原因（公司策略、硬件限制等），请联系组委会，我们会人工评估。

**Q：反作弊会不会扫我的隐私 / 上传我的文件？**
A：不会。它只做三件事：校验运行环境、监听模拟器的状态写入、签发心跳票据。它不读取你的个人文件，不上传任何数据。源码摘要随赛事包提供，可自行核对。

**Q：我能改反作弊吗？**
A：本机上的任何东西你都可以改。但请注意——它是否正常签发票据，是 Task 3 判定的一部分。

**Q：卡住了怎么办？**
A：服务器公告会按时间梯度释放提示。也可以在答疑频道提问。
